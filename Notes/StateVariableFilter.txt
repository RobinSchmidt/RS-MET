Algorithm for computing the mixing coefficients aL, aB, aH for achieving the RBJ cookbook transfer
functions:

As mystran explains on KVR, the analog prototype response of the SVF is:

          aL + aB s + aH s^2
  H(s) = --------------------
          1  + s/Q  + s^2

so the a-coefficients are the polynomial coefficients of the numerator of the s-domain 
transfer function. If we can manage to bring a given s-domain transfer function into this form,
then we can directly read off our mixing coeffs from the transfer function. Among the RBJ
cookbook filters, the lowpass, highpass, bandpass, bandstop and allpass transfer functions are 
indeed of this form, so we can directly read off our a-coeffs from these. For the peak/bell 
filter, the RBJ prototype response is of the form:

          1 + s*(A/Q) + s^2
  H(s) = -------------------
          1 + s/(A*Q) + s^2

which is not exactly of the right form because in the denominator, we see an  s/(A*Q)  term 
instead of the desired  s/Q  term. But by letting  P = A*Q  we can replace  A*Q  by  P in
the denominator and in the numerator replace  Q  by  P/A  to get:
 
          1 + s*A^2/P + s^2
  H(s) = --------------------
          1 +   s/P   + s^2

This substitution can be automated using the following Sage code:

  var("s Q A P")
  H = (s^2 + s*(A/Q) + 1) / (s^2 + s/(A*Q) + 1)
  G = H.subs(Q == P/A)
  G

which produces the output:  (A^2*s/P + s^2 + 1)/(s^2 + s/P + 1))  where G is in the desired 
form but with P instead of Q. We can now just use P in place of Q and get our mixing coeffs as
a0 = a2 = 1, a1 = A^2/P = A/Q. 


For the low shelving filter, the RBJ prototype transfer function is:

              s^2  + (sqrt(A)/Q)*s + A      A^2 + (sqrt(A)/Q)*s + s^2
  H(s) = A * --------------------------- = -----------------------------
              A*s^2 + (sqrt(A)/Q)*s + 1      1  + (sqrt(A)/Q)*s + A*s^2

Now we have two problems: the factor for s as well the one for s^2 is wrong. Instead of
1/Q and 1 as coeffs for s and s^2, we see sqrt(A)/Q and A. Both problems can be solved by
substituting  t = s*sqrt(A), i.e. s = t/sqrt(A). The following Sage snippet solves does this:

  var("s Q A t")
  H = A*(s^2+sqrt(A)/Q*s+A)/(A*s^2+sqrt(A)/Q*s+1)
  G = H.subs(s == t/sqrt(A))
  G

which produces:  (A + t^2/A + t/Q)*A/(t^2 + t/Q + 1). Again, we can read off the a0,a1,a2 
coeffs from G as a0 = A, a1 = 1/Q, a2 = 1/A. Our  s <-> t  substitution means that we now must
scale the frequencies because that's the effect of multiplying s by a factor. But those coeffs
will give a response that is off from the desired one by a scaling factor. The high frequency 
gain is supposed to be unity and it is given by coeff in front of t^2, so it would be 1/A. To get
it back to unity, we need to scale all coeffs by A such that:  a0 = A^2, a1 = A/Q, a2 = 1.

For the high shelf the prototype transfer function is:

              A*s^2 + (sqrt(A)/Q)*s + 1     1 + (sqrt(A)/Q)*s + A*s^2
  H(s) = A * --------------------------- = ---------------------------
              s^2 + (sqrt(A)/Q)*s + A       A + (sqrt(A)/Q)*s + s^2

With this Sage code:

  var("s Q A t")
  H = A * (A*s^2 + (sqrt(A)/Q)*s + 1)/(s^2 + (sqrt(A)/Q)*s + A)
  G = H.subs(s == t*sqrt(A))
  G

We get:  (A^2*t^2 + A*t/Q + 1)*A/(A*t^2 + A + A*t/Q). Apparently, Sage didn't fully simplify the
expression. We can cancel the A to get: (A^2*t^2 + A*t/Q + 1)/(t^2 + 1 + t/Q) so we read off:
a0 = 1, a1 = A/Q, a2 = A^2. This time, we don't need to scale anything. The a0 coeff, i.e. the 
lowpass gain, already came out as 1 as it should for high-shelving filter.

Algorithms to compute transfer function and convert from/to direct form biquad:

We want to find the z-domain transfer function for the SVF. We have the equations:

         Time domain                                       z-domain

  h[n] = s*x[n] - s*c*u[n-1] - s*v[n-1]   <-->   H(z) = s*X(z) - s*c*z^-1 * U(z) - s*z^-1 * V(z)
  b[n] = g*h[n] + u[n-1]                  <-->   B(z) = g * H(z) + z^-1 * U(z)
  l[n] = g*b[n] + v[n-1]                  <-->   L(z) = g * B(z) + z^-1 * V(z)
  u[n] = 2*b[n] - u[n-1]                  <-->   U(z) = 2 * B(z) - z^-1 * U(z)
  v[n] = 2*l[n] - v[n-1]                  <-->   V(z) = 2 * L(z) - z^-1 * V(z)

where h[n], b[n], l[n] are the time domain highpass, bandpass and lowpass signals and u[n], v[n] are
the integrator states and H(z), etc. are the corresponding z-transforms of these signals (Warning: 
in this notation, H(z) is *not* a transfer function but the z-trafo of the highpass signal h[n]).
In terse form:

  H = s*X - s*c*U*d - s*V*d                                                                     (1)
  B = g*H + U*d                                                                                 (2)
  L = g*B + V*d                                                                                 (3)
  U = 2*B - U*d                                                                                 (4)
  V = 2*L - V*d                                                                                 (5)

What we eventually want are expressions for the highpass transfer function H/X, the bandpass
transfer function B/X and the lowpass transfer function L/X. Here is the SageMath code that solves 
this problem:

var("d  s c g  X H B L U V  TF_H TF_B TF_L")
e1 = H == s*X - s*c*U*d - s*V*d
e2 = B == g*H + U*d
e3 = L == g*B + V*d
e4 = U == 2*B - U*d
e5 = V == 2*L - V*d
e6 = TF_H == H/X
e7 = TF_B == B/X
e8 = TF_L == L/X
sH = solve([e1,e2,e3,e4,e5, e6],[TF_H, H,B,L,U,V])
sB = solve([e1,e2,e3,e4,e5, e7],[TF_B, H,B,L,U,V])
sL = solve([e1,e2,e3,e4,e5, e8],[TF_L, H,B,L,U,V])
sH[0][0], sB[0][0], sL[0][0]

It gives the result (re-formatted by me):

  (TF_H ==  (d^2     - 2*d       + 1)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1),
   TF_B == -(d^2*g   -             g)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1),
   TF_L ==  (d^2*g^2 + 2*d*g^2 + g^2)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1))

To find the biquad denominator coeffs, we could use the following code to extract the coeffs for 1, 
z^-1 and z^-2:

var("d c g s")
D = (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1)
D.expand()
a0 = D(d=0)               # a0 = D.coefficient(d^0) returns 0. Why?
a1 = D.coefficient(d)
a2 = D.coefficient(d^2)
a0, a1, a2

  ->  (1, 2*(c*g + g^2)*s - 2, -2*(c*g - g^2)*s + 1)

For a0, we just evaluated the expression at zero. Trying to retrieve the a0 coefficient via 
a0 = D.coefficient(1) or a0 = D.coefficient(d^0) returns 0 (Why?). OK - so now we have formulas to 
compute the coefficients for an equivalent direct form biquad filter with transfer function:

           b0 + b1*z^-1 + b2*z^-2
   H(z) = ------------------------
           1  + a1*z^-1 + a2*z^-2

from our SVF coeffs s,c,g,aH,aB,aL. They are given by:

  ┌─────────────────────────────────────┐
  │ b0 =  aL*s*g*g    + aB*g*s + aH*s   │
  │ b1 =  aL*s*g*g*2           - aH*s*2 │
  │ b2 =  aL*s*g*g    - aB*g*s + aH*s   │
  │ a1 =  2*(c*g + g*g)*s - 2           │
  │ a2 = -2*(c*g - g*g)*s + 1           │
  └─────────────────────────────────────┘

Next, we may be interested in doing it the other way around, i.e. starting from biquad coeffs and 
trying to find the coeffs of an equivalent SVF. Trying to solve the set of equations with SageMath:

var("b0 b1 b2 a1 a2  aL aB aH g r")
s = 1 / (1 + g*(g+r))
e1 = b0 == aL*s*g*g    + aB*g*s + aH*s
e2 = b1 == aL*s*g*g*2           - aH*s*2
e3 = b2 == aL*s*g*g    - aB*g*s + aH*s
e4 = a1 ==  2*((g+r)*g + g*g)*s - 2
e5 = a2 == -2*((g+r)*g - g*g)*s + 1
solve([e1,e2,e3,e4,e5],[aL,aB,aH,g,r])

produces two solutions:

  Intermediates:
  T  =         (a1^2 - a2^2 - 2*a2 - 1)
  S  = sqrt(-1/(a1^2 - a2^2 - 2*a2 - 1)) = sqrt(-1/T)

  1st solution:
  aB ==  2*b0*S - 2*b2*S
  g  == -1/((a1 - a2 - 1)*S)
  r  ==  2*(a2 - 1)/(T * S) 

  2nd solution:
  aB == -2*b0*S + 2*b2*S
  g  ==  1/((a1 - a2 - 1)*S)
  r  == -2*(a2 - 1) / (T * S)

  Common computations:
  aH = -(b0 - b1 + b2) / (a1 - a2 - 1);
  aL =  (b0 + b1 + b2) / (a1 + a2 + 1);
  c  =  g + r;
  s  =  1 / (1 + g*c);

I'm not sure what to do with that result, though. It seems to work only when T < 0 but I think the 
case with T >= can correspond to totally legitimate biquad filters. I think, it's not even related 
to (in)stability even though instability shouldn't even be a problem for these formulas anyway. For 
the common RBJ filters, the formulas of the first solution seem to work, though. With some manual
simplifications, we can bring that into the following form:

  ┌────────────────────────────┐
  │ // Intermediates:          │
  │ T1 = a1 - a2 - 1           │
  │ T2 = a1 + a2 + 1           │
  │ T  = T1 * T2               │
  │ S  = sqrt(-1 / T)          │    T needs to be < 0 for this to work
  │ r  = 2*(a2 - 1) / (T*S)    │
  │                            │
  │ // Coefficients:           │
  │ aH = -(b0 - b1 + b2) / T1  │
  │ aB =  (b0      - b2) * 2*S │
  │ aL =  (b0 + b1 + b2) / T2  │
  │ g  = -1 / (T1*S)           │
  │ c  =  g + r                │
  │ s  =  1 / (1 + g*c)        │
  └────────────────────────────┘

I have implemented these formulas in rsStateVariableFilter::setupFromBiquad(). If T is positive, 
then  S = sqrt(-1/T)  becomes imaginary. Therefore, r becomes imaginary, too. I think, r is supposed
to be some sort of damping coefficient. What does it mean when a damping coefficient becomes 
imaginary? It also seems that the formulas given by Aaron Wishnick in this paper (in Eq. 16):

  https://www.dafx14.fau.de/papers/dafx14_aaron_wishnick_time_varying_filters_for_.pdf

do have similar problems. Obviously, the formulas ought to be equivalent - they are just written 
down a little bit differently.

References:

- https://www.kvraudio.com/forum/viewtopic.php?p=8992653#p8992653  
  Teemu Voipio (aka mystran) explains how to set up the mixing coefficients to achieve the well 
  known RBJ cookbook transfer functions. This discussion was what prompted me to re-implement the 
  SVF using these ideas to compute the mixing coefficients. 

- The Art of Virtual Analog Filter Design
  Vadim Zavalishin's excellent book has a chapter about ZDF-SVF filters (and much more good stuff).
  This was what my earlier implementation was based on.

- https://www.cytomic.com/files/dsp/SvfLinearTrapOptimised2.pdf
  Andrew Simper describes a filter implementation that is very similar. But this filter mixes its 
  final output not from highpass, bandpass and lowpass parts but rather from input, bandpass and 
  lowpass. These are two variations of the same filter.

- https://www.dafx14.fau.de/papers/dafx14_aaron_wishnick_time_varying_filters_for_.pdf
  Aaron Wishnick's paper has formulas (equation 16 a-c) for converting from direct form biquad 
  coefficients to SVF coeffs. They are similar to the formulas given above.

- https://github.com/RobinSchmidt/RS-MET/blob/work/Notes/OtherAuthors/Audio-EQ-Cookbook.txt
  Robert Bristow Johnson's classic biquad filter cookbook. The response types realized here are
  precisely those described there.
