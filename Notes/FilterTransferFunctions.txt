We want to figure out a general way for how to find expressions for z-domain filter transfer 
functions for a given time domain filtering algorithm in the form of a set of difference equations.
The transfer function of a filter is the ratio of the z-transforms of the output signal and the 
input signal of the filter, i.e. H(z) = Y(z)/X(z). 


First Order Direct Form 1 filter
--------------------------------

Let's start with a very simple first order direct form 1 (DF1) filter as warm up. In this case, the 
derivation of H(z) = Y(z) / X(z) proceeds as follows:

  y[n] = b0*x[n] + b1*x[n-1] - a1*y[n-1]                Translate to z-domain

  Y(z) = b0*X(z) + b1*z^-1*X(z) - a1*z^-1*Y(z)          Move Y(z) terms to left and X(z) to right
  Y(z) + a1*z^-1*Y(z) = b0*X(z) + b1*z^-1*X(z)          Factor out Y and X
  Y(z) (1 + a1*z^-1) = X(z)  (b0 + b1*z^-1)             Solve for Y(z)/X(z) and call that H(z)

  H(z) = Y(z)/X(z) = (b0 + b1*z^-1) / (1 + a1*z^-1)     Done

That way easy enough and the procedure can be generalized to DF1 filters of arbitrary order. The 
order doesn't make it more complicated, just the polynomials will get longer.


First Order Direct Form 2 filter
--------------------------------

Let's as the next step try it with a direct form 2 (DF2) filter to see how to deal with intermediate 
variables. For the filter block diagram, see:
  
  https://www.dsprelated.com/freebooks/filters/Direct_Form_II.html

The time domain difference equations and z-domain algebraic equations look like this:

         Time domain                              z-domain

  v[n] = x[n] - a1*v[n-1]       <-->     V(z) = X(z) - a1*z^-1*V(z)
  y[n] = b0*v[n] + b1*v[n-1]    <-->     Y(z) = b0*V(z) + b1*z-^1*V(z)

To make things more easy to write, we will used the substituation d = z^-1 (you may read the d as
"delay") and suppress the argument, i.e. wil will just write X,V,Y instead of X(z),V(z),Y(z). With
that in place, we can write for the z-domain equations:

  V = X - a1*V*d
  Y = b0*V + b1*V*d  

Again, we want to solve for Y/X. Let's solve the 1st equation for V:

  V + a1*V*d = X = V(1 + a1*d)  
  V = X / (1 + a1*d)

and plug that result into the 2nd equation:

  Y = b0*(X / (1 + a1*d)) + b1*(X / (1 + a1*d))*d 
    = (X / (1 + a1*d)) * (b0 + b1*d)
    = (b0 + b1*d)* X / (1 + a1*d)

And now divide both sides by X to get H = Y/X:

  H = Y/X = (b0 + b1*d) / (1 + a1*d) 
    = (b0 + b1*z^-1) / (1 + a1*z^-1)

which is the same result as it should be. Instead of doing it by hand, it makes sense to automate 
the job by handing is to a computer algebra system. The following code for SageMath produces the
solution:

var("b0 b1 a1 d X Y V H")       # b0,b1,a1: filter coeffs, d = z^-1, X=X(z),Y=Y(Z),etc.
e1 = V == X - a1*V*d            # 1st equation from the filter's state update
e2 = Y == b0*V + b1*V*d         # 2nd equation from the filter's output computation
V_X = solve([e1],[V])           # V_X =  [V == X/(a1*d + 1)], V in terms of X
e3  = e2.subs(V=V_X[0].rhs())   # e3  =  Y == X*b1*d/(a1*d + 1) + X*b0/(a1*d + 1)
e3  = e3.simplify_full()        # e3  =  Y == (X*b1*d + X*b0)/(a1*d + 1)
e4  = H == Y/X                  # Introduce auxiliary equation for H(z) = Y(z)/X(z)
sln = solve([e3,e4],[H,Y])      # solve([e3,e4],[H,X]) works also
sln[0][0]                       # Prints the solution: H == (b1*d + b0)/(a1*d + 1)

It is important to ask the solver to solve for [H,Y] and not just for [H] even though we are 
eventually only interested in H. But trying to just use  sln = solve([e3,e4],[H])  will not work.
It will produce an empty solution set. I guess it has to do with having two equations for one 
variable, i.e. 2 constraints and only 1 degree of freedom. The code snippet can be copy-and-pasted 
and executed here https://sagecell.sagemath.org/. It produces the desired output:

  H == (b1*d + b0)/(a1*d + 1)

Apparently, the solution sln is an array with two indices (Why? Wouldn't one index be enough?). The
second element is an expression for Y which we are not interested in. Just for info, it is:
Y == (X*b1*d + X*b0)/(a1*d + 1). That might actually be useful because one can read off the DF1 
implementation from it. The Sage code above can be simplified. We don't really need to do the 
intermediate solutions, substitution and simplifcations manually to get down to one equation plus
our auxiliary. This code here also works:

var("b0 b1 a1 d X Y V H")         # b0,b1,a1: filter coeffs, d = z^-1, X=X(z),Y=Y(Z),etc.
e1 = V == X - a1*V*d              # 1st equation from the filter's state update
e2 = Y == b0*V + b1*V*d           # 2nd equation from the filter's output computation
e3 = H == Y/X                     # Auxiliary equation for H(z) = Y(z)/X(z)
sln = solve([e1,e2,e3],[H,X,Y])   # Solve the system of equations 
sln[0][0]                         # The 1st element is what we are interested in

Here, we used the original 2 equations and introduced the auxiliary H = Y/X equation as 3rd equation 
and solved for 3 variables H,X,Y. Again, we are mainly interested in H.


Moog Ladder with Unit Delay Feedback (UDF)
------------------------------------------

As the next example, let's have a look at a Moog-style ladder filter that is built from 4 one
pole filters with a feedback loop that includes a unit delay. We define the difference equation and
transfer function of the 1-pole as:

  g1[n] = b0*x[n] - a1*g1[n-1]      <-->    G1(z) = b0 / (1 + a1*z-^1)

Four of such filters in series give G4(z) = (G1(z))^4:

  G4(z) = (b0 / (1 + a1*z-^1))^4  
        = (b0 / (1 + a1*d))^4

We could expand this but it turns out to be more convenient to leave it in this form. The complete
transfer function with feedback is given by:

  H(z) = G4(z) / (1 + k*z^-1*G4(z))   or more tersely   H = G4 / (1 + k*d*G4)

This is implemented in rsLadderFilter::getTransferFunctionAt() but with additional mixing of the 
filter output stages (which is an add-on functionality that this filter has to obtain response
types other than 4th order lowpass). 


State Variable Filter with Zero Delay Feedback (ZDF)
----------------------------------------------------

Now we want to look into a more complicated filter and try to write down the z-domain transfer 
function for that. Namely, the zero delay feedback (ZDF) state variable filter (SVF). For this 
filter, we have the equations:

         Time domain                                       z-domain

  h[n] = s*x[n] - s*c*u[n-1] - s*v[n-1]   <-->   H(z) = s*X(z) - s*c*z^-1 * U(z) - s*z^-1 * V(z)
  b[n] = g*h[n] + u[n-1]                  <-->   B(z) = g * H(z) + z^-1 * U(z)
  l[n] = g*b[n] + v[n-1]                  <-->   L(z) = g * B(z) + z^-1 * V(z)
  u[n] = 2*b[n] - u[n-1]                  <-->   U(z) = 2 * B(z) - z^-1 * U(z)
  v[n] = 2*l[n] - v[n-1]                  <-->   V(z) = 2 * L(z) - z^-1 * V(z)

where h[n], b[n], l[n] are the time domain highpass, bandpass and lowpass signals and u[n], v[n] are
the integrator states and H(z), etc. are the corresponding z-transforms of these signals (Warning: 
in this notation, H(z) is *not* a transfer function but the z-trafo of the highpass signal h[n]).
In terse form:

  H = s*X - s*c*U*d - s*V*d                                                                     (1)
  B = g*H + U*d                                                                                 (2)
  L = g*B + V*d                                                                                 (3)
  U = 2*B - U*d                                                                                 (4)
  V = 2*L - V*d                                                                                 (5)

What we eventually want are expressions for the highpass transfer function H/X, the bandpass
transfer function B/X and the lowpass transfer function L/X. Let's first solve the last 2 equations 
for U and V:

  U = 2*B - U*d  ->  U + U*d = 2*B  ->  U*(1+d) = 2*B  ->  U = (2*B/(1+d))                      (6)
  V = 2*L - V*d  ->    ....the very same stuff.....    ->  V = (2*L/(1+d))                      (7)

And plug the results into the first 3 equations:

  H = s*X - s*c*(2*B/(1+d))*d - s*(2*L/(1+d))*d                                                 (8)
  B = g*H + (2*B/(1+d))*d                                                                       (9)
  L = g*B + (2*L/(1+d))*d                                                                      (10)

Now let's solve the 3rd one for B. We just need to subtract (2*L/(1+d))*d from both sides and 
divide by g:

  B = (L - (2*L/(1+d))*d)/g                                                                    (11)

and plug that into the 2nd:

  ((L - (2*L/(1 + d))*d)/g) = g*H + (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d                    (12)

Now let's solve this one for H:

  H = ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g)                (13)

and plug it into the equation (8):

  ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g) 
  = s*X - s*c*(2*B/(1 + d))*d - s*(2*L/(1 + d))*d
 
This is already a mess - but it gets even messier: We now replace B by the expression 
((L - (2*L/(1 + d))*d)/g) that we calculated before:

  ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g) 
  = s*X - s*c*(2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d - s*(2*L/(1 + d))*d

Let's try to simplify both sides with Sage:

var("d g L") 
lhs = ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g) 
lhs.simplify_full()
 
  ->  (L*d^2 - 2*L*d + L)/((d^2 + 2*d + 1)*g^2)

var("d g s c L X") 
rhs = s*X - s*c*(2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d - s*(2*L/(1 + d))*d
rhs.simplify_full()

  ->  (2*L*c*d^2 - 2*L*c*d - ((2*L - X)*d^2 + 2*(L - X)*d - X)*g)*s/((d^2 + 2*d + 1)*g)
  
We have now whittled the whole system down to a single equation that contains only  L,X  and the 
constants  g,s,c  and the delay operator  d  and its square  d^2  indicating a 2-sample delay. The 
equation is a quite messy:

                    (L*d^2 - 2*L*d + L)/((d^2 + 2*d + 1)*g^2)

                                       =

        (2*L*c*d^2 - 2*L*c*d - ((2*L - X)*d^2 + 2*(L - X)*d - X)*g)*s/((d^2 + 2*d + 1)*g)

This is now the single equation that we need to bring into the form  L/X = "something"
where that "something" is a 2nd order rational function in d that contains only g,s,c and d, d^2.
This will then be the transfer function that is applied the lowpass signal. Looking at the 
denominators of both sides, we see that we can actually cancel  (d^2 + 2*d + 1)*g  from both 
denominators. Only on the left hand side a g remains becuase it has a g^2 in it. So, the equation 
simplifies to:

  (L*d^2 - 2*L*d + L) / g = (2*L*c*d^2 - 2*L*c*d - ((2*L - X)*d^2 + 2*(L - X)*d - X)*g)*s

That looks a whole lot better already. Now let's expand the right hand side:

var("X L g c s d")
expr = (2*L*c*d^2 - 2*L*c*d - ((2*L - X)*d^2 + 2*(L - X)*d - X)*g)*s
expr.expand()

  ->  2*L*c*d^2*s - 2*L*d^2*g*s + X*d^2*g*s - 2*L*c*d*s - 2*L*d*g*s + 2*X*d*g*s + X*g*s

and write our equation as:

  L*d^2/g - 2*L*d/g + L/g 
  = 
  2*L*c*d^2*s - 2*L*d^2*g*s + X*d^2*g*s - 2*L*c*d*s - 2*L*d*g*s + 2*X*d*g*s + X*g*s

and bring all L-terms to the left (i.e. top):

  L*d^2/g - 2*L*d/g + L/g - 2*L*c*d^2*s + 2*L*d^2*g*s + 2*L*c*d*s + 2*L*d*g*s 
  = 
  X*d^2*g*s + 2*X*d*g*s + X*g*s

Factor out L on the left and X on the right:

  L * (d^2/g - 2*d/g + 1/g - 2*c*d^2*s + 2*d^2*g*s + 2*c*d*s + 2*d*g*s)
  = 
  X * (d^2*g*s + 2*d*g*s + g*s)

And this can now easily rearranged into L/X = "something" form as:

   L                   d^2*g*s + 2*d*g*s + g*s
  --- = -----------------------------------------------------------------
   X     d^2/g - 2*d/g + 1/g - 2*c*d^2*s + 2*d^2*g*s + 2*c*d*s + 2*d*g*s


   L                   d^2*g*s + 2*d*g*s + g*s
  --- = ----------------------------------------------------------------------                 (14)
   X     1/g   - 2*d/g + 2*c*d*s + 2*d*g*s  +  d^2/g - 2*c*d^2*s + 2*d^2*g*s 

This is our desired final form of:

   L/X = (b0 + b1*d + b2*d^2) / (a0 + a1*d + a2*d^2)

with 

  ┌───────────────────────────────────────────────────────────────────────────────────────────────┐
  │ b0 = g*s, b1 = 2*g*s, b2 = g*s, a0 = 1/g, a1 = -2/g + 2*c*s + 2*g*s, a2 = 1/g - 2*c*s + 2*g*s │
  └───────────────────────────────────────────────────────────────────────────────────────────────┘

For the highpass and bandpass transfer function, we need to do something similar to end up with 
expressions for B/X and H/X ...or maybe we could backsubstitute our lowpass result somewhere?
Let's look back at equation (13) which is repeated here:

  H = ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g)   

Maybe let's try to express L as X times the right hand side of equation (14) and substitute it in.
But this is something we really don't want to do by hand, so:

var("X H d g s c")
num = X * (d^2*g*s + 2*d*g*s + g*s)
den = d^2/g - 2*d/g + 1/g - 2*c*d^2*s + 2*d^2*g*s + 2*c*d*s + 2*d*g*s
L   = num / den
H   = ((((L - (2*L/(1 + d))*d)/g) - (2*((L - (2*L/(1 + d))*d)/g)/(1 + d))*d)/g) 
H.simplify_full()

  -> (X*d^2 - 2*X*d + X)*s/(d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

so we have established that:

  H = (X*d^2 - 2*X*d + X)*s / (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

We factor out X on the right hand side:

  H = X(d^2 - 2*d + 1)*s / (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

and bring it over to the left:

   H                 (d^2 - 2*d + 1)*s
  --- = ---------------------------------------------------------
   X     (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

var("d g s c")
expr = (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)
expr.expand()

  -> -2*c*d^2*g*s + 2*d^2*g^2*s + 2*c*d*g*s + 2*d*g^2*s + d^2 - 2*d + 1

So:

   H                        s - s*2*d + s*d^2
  --- = -----------------------------------------------------------------------
   X      1  +  2*c*d*g*s + 2*d*g^2*s - 2*d  - 2*c*d^2*g*s + 2*d^2*g^2*s + d^2

We read off:

  ┌────────────────────────────────────────────────────────────────────────────────────────────┐
  │ b0 = s, b1 = -2*s, b2 = s, a0 = 1, a1 = 2*c*g*s + 2*g*g*s - 2, a2 = -2*c*g*s + 2*g*g*s + 1 │
  └────────────────────────────────────────────────────────────────────────────────────────────┘

OK - and now finally for the bandpass. For this, we go back to equation (12) which is repeated here:

  B = (L - (2*L/(1+d))*d)/g  

and do the same procedure.

var("X B d g s c")
num = X * (d^2*g*s + 2*d*g*s + g*s)
den = d^2/g - 2*d/g + 1/g - 2*c*d^2*s + 2*d^2*g*s + 2*c*d*s + 2*d*g*s
L   = num / den
B   = (L - (2*L/(1+d))*d)/g  
B.simplify_full()
 
  ->  -(X*d^2 - X)*g*s/(d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

so we have established that:

  B = -(X*d^2 - X)*g*s / (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

We factor out X on the right hand side:

  B = -X(d^2 - 1)*g*s / (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)

and bring it over to the left:

   B                   -(d^2 - 1)*g*s                                  g*s - g*s*d^2
  --- = --------------------------------------------------------- = -------------------
   X     (d^2 + 2*((d^2 + d)*g^2 - (c*d^2 - c*d)*g)*s - 2*d + 1)        Denominator

We recognize that the denominator is the same as in the highpass case, so our a0,a1,a2 coeffs will
be the same as for highpass. The b-coeffs are: 

  ┌────────────────────────────────────────────────────────────┐
  │ b0 = g*s, b1 = 0, b2 = -g*s, a-coeffs same as for highpass │
  └────────────────────────────────────────────────────────────┘

That was quite a messy derivation. Later, I figured out how to let Sage do it. Here is the code:

var("d  s c g  X H B L U V  TF_H TF_B TF_L")
e1 = H == s*X - s*c*U*d - s*V*d
e2 = B == g*H + U*d
e3 = L == g*B + V*d
e4 = U == 2*B - U*d
e5 = V == 2*L - V*d
e6 = TF_H == H/X
e7 = TF_B == B/X
e8 = TF_L == L/X
sH = solve([e1,e2,e3,e4,e5, e6],[TF_H, H,B,L,U,V])
sB = solve([e1,e2,e3,e4,e5, e7],[TF_B, H,B,L,U,V])
sL = solve([e1,e2,e3,e4,e5, e8],[TF_L, H,B,L,U,V])
sH[0][0], sB[0][0], sL[0][0]

It gives the result (re-formatted by me):

  (TF_H ==  (d^2     - 2*d       + 1)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1),
   TF_B == -(d^2*g   -             g)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1),
   TF_L ==  (d^2*g^2 + 2*d*g^2 + g^2)*s  /  (d^2 - 2*((c*g - g^2)*d^2 - (c*g + g^2)*d)*s - 2*d + 1))

   H                 (d^2 - 2*d + 1)*s
